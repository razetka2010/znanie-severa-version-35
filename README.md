## 📖 Описание

**Знание Севера v35** - это веб-приложение для управления образовательным процессом, разработанное для организации взаимодействия между администраторами, учителями и студентами.

Проект предоставляет интегрированную платформу с различными ролями пользователей и функциональностью для эффективного управления учебной деятельностью.

---

## 🎯 Основные функции

✅ **Для администраторов**
- Управление пользователями и правами доступа
- Управление учебными курсами и классами
- Аналитика и отчёты по образовательному процессу
- Конфигурация системы

✅ **Для учителей**
- Создание и редактирование уроков
- Выставление оценок студентам
- Отслеживание прогресса учеников
- Коммуникация со студентами

✅ **Для студентов**
- Просмотр расписания уроков
- Отправка домашних заданий
- Просмотр оценок и отзывов
- Отслеживание своего прогресса

## 🚀 Быстрый старт

### Предварительные требования
- Современный браузер (Chrome, Firefox, Safari, Edge)
- Текстовый редактор для редактирования файлов (опционально)

### Установка

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/razetka2010/znanie-severa-version-35.git
cd znanie-severa-version-35
```

2. **Откройте приложение в браузере:**
```bash
# Просто откройте один из файлов HTML в браузере
# index.html - для студентов
# admin.html - для администраторов
# teacher.html - для учителей
```

Или используйте локальный сервер:
```bash
python -m http.server 8000
# Затем откройте http://localhost:8000
```

## 📝 Использование

### Для студентов:
1. Откройте `index.html` в браузере
2. Авторизуйтесь в системе
3. Просмотрите доступные курсы и расписание
4. Отправляйте домашние задания

### Для учителей:
1. Откройте `teacher.html`
2. Войдите в свой аккаунт
3. Управляйте классами и уроками
4. Выставляйте оценки и отзывы

### Для администраторов:
1. Откройте `admin.html`
2. Авторизуйтесь как администратор
3. Управляйте пользователями и системой
4. Просматривайте аналитику
